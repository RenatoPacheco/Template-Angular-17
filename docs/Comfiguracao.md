# Configuração do projeto

### Pacotes & programas globais

* `NodeJS 20.18.3` https://nodejs.org/pt/download/current
* `Npm 11.1.0` npm i -g npm@11.1.0
* `Angular 17` npm i -g @angular/cli@17

### Instalação

```sh
ng new adm-teste --routing=true --style=scss --ssr=true
```

### Outros pacotes

* `Font Awesome 4` npm install font-awesome
* `Guid Typescript` npm i guid-typescript

```sh
npm install font-awesome guid-typescript
```
